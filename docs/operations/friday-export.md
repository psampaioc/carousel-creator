# Friday carousel export runbook

Use this process on Friday to prepare the following Monday-Sunday edition. The app creates files in Google Drive; it never publishes to Instagram.

## Before export

1. Open the review queue and confirm every selected event remains approved.
2. Open every source and compare the displayed date, time, place, event status, and title with the current source.
3. Resolve every conflict and import finding. Remove cancelled, stale, or unsupported events.
4. Check the selected image for each event. Confirm its original source and whether it is official, an announcement, or generated.
5. Mark factual review complete for every slide whose copy changed.
6. Read the carousel in order. Confirm the cover is first, online events are only on the final slide, wider-area events are described honestly, and there are no filler events.

## Export

1. Select **Export reviewed carousel**.
2. Keep the page open while the app renders 1080 × 1350 PNG files and uploads them.
3. Confirm the success message reports the expected slide count.
4. Open `exports/YYYY/YYYY-MM-DD-week-start/` in the configured Drive project folder.
5. Confirm the numbered files run from `01` without gaps and visually inspect every PNG before publication.

Retrying is safe: files with the same numbered name are updated rather than duplicated. If rendering or upload fails, the draft stays editable. Correct the reported problem and retry.

## Manual publication check

Before uploading the files to Instagram, perform one last source/date/place/image-attribution check against the Drive exports. Write the post copy separately and publish manually. The app must not receive Instagram publishing credentials.
